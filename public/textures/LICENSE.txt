SOURCES.json lists each asset, source page, and available author credits.
Ground materials use 2K diffuse and OpenGL normal maps. Some prop materials use 1K maps. The sky uses a 2K HDR.
Pine foliage uses the twig atlas from pine_tree_01, with a shaped branch card.
All files ship locally with the game; no runtime asset service is required.
